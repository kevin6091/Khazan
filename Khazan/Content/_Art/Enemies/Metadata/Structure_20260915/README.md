# Enemy Asset Library Structure 2026-09-15

`CurrentAssets.json` and `AssetLibrary.csv` are the canonical lookup for all current Enemy assets.
`RenameMap.json` maps the 21 former package paths to their current paths.
`FolderStructure.json` summarizes each gameplay family and asset class.
`ValidationSummary.json` records the fresh Unreal audit.
`EmptyDirectoryCleanup.json` records removed folders. Historical files whose names include Legacy or Archive remain as provenance records and are not runtime assets.
