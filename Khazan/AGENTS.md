# Khazan 작업 문서 규칙

1. 모든 작업은 먼저 `0_DOCUMENT_ROUTER.md` 하나만 읽고 요청 도메인을 판정한다.
2. Art 작업은 `Docs/Art`의 필요한 문서만 읽고 갱신한다.
3. Engineering 작업은 `Docs/Engineering`의 필요한 문서만 읽고 갱신한다.
4. 요청이 두 도메인에 걸칠 때만 양쪽의 최소 문서 집합을 읽고, 결과도 각 도메인 문서에 분리 기록한다.
5. 루트의 `1_PROJECT_STATE.md`부터 `7_RUNTIME_CRASH_DIAGNOSTICS.md`까지는 마이그레이션 전 레거시 기록이다. 라우터가 특정 정보를 찾기 위해 지목한 경우가 아니면 선행해서 읽거나 갱신하지 않는다.
6. 문서는 기존 기록을 덮어쓰거나 삭제하지 않고 날짜별 섹션을 하단에 추가한다.
7. 작업이 중단되거나 완료하지 못할 가능성이 있으면 해당 도메인의 `*_WORK_CONTINUITY.md`에 현재 상태, 마지막 검증, 실패 원인, 남은 작업, 정확한 재개 절차를 기록한다.
8. 전수조사는 기존 도메인 지식 문서와 저장된 metadata/report로 답할 수 없을 때만 수행한다. 불가피한 전수조사 결과는 해당 도메인 지식 문서에 재사용 가능한 형태로 남긴다.
